# Dolomite Margin : architecture

L’architecture sépare les contrats de base, les modules spécialisés et les intégrations. Cette séparation rend les responsabilités lisibles : margin engine, accounts, markets, borrow positions, adapters, liquidations, oracles. Les paramètres critiques doivent toujours être vérifiés dans la version déployée.
